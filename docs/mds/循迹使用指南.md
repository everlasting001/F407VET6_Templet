# 正方形边框循迹使用指南 (Task1)

## 一、功能概述

Task1 实现小车对 **100cm×100cm 正方形边框** 的完整循迹一圈。小车从边框任意位置出发，沿黑色边界线行驶，在四个直角拐角处自动检测路口并执行 90° 转弯，完成 4 条边后自动停车。

### 硬件依赖

| 模块 | 接口 | 用途 |
|------|------|------|
| 八路灰度循迹传感器 | AD0-AD2/OUT (GPIOD) | 直线循线 + 直角路口检测 |
| 左轮编码器 | TIM1 编码器模式 | 路口微调前进距离计量 |
| 右轮编码器 | TIM8 编码器模式 | 同上 |
| MPU6050 陀螺仪 | I2C1 DMA | 直角转弯 Yaw 角闭环控制 |
| 左右直流电机 | TIM3 CH1/CH2 PWM | 差速驱动 |

## 二、巡线状态机

```
                 路口检测                       转弯完成
FOLLOWING ──────────> FORWARD_ADJUST ──────────> TURNING ──────────> EDGE_DONE
    ^                     │                          │                    │
    |                     │ 微调前进 align_distance  │ 陀螺仪Yaw闭环90°   │
    |                     └──────────────────────────┘                    │
    |                                                                    │
    +------- edge_count < 4 (切换下一条边) --------------------------------+
    |
    +------- edge_count >= 4 (全部完成，停车) —————> MOVE_STATE_COMPLETE
```

### 各状态说明

| 状态 | 功能 | 持续时间 |
|------|------|---------|
| **FOLLOWING** | 加权差速循线 + 路口检测 | 直到检测到路口 |
| **FORWARD_ADJUST** | 微调前进使轮轴对齐路口中心 | 前进 ~60mm |
| **TURNING** | 陀螺仪 Yaw P 控制 90° 转弯 | 直到 Yaw 到达目标 |
| **EDGE_DONE** | 边计数+1，复位 Yaw，切换或停止 | 瞬时 |

### 路口检测逻辑

一侧 4 路传感器同时检测到黑线 或 6 路以上同时检测到黑线 → 疑似路口。
连续确认 3 次 (3×2ms=6ms) 后判定为有效路口，避免传感器噪声误触发。

## 三、集成步骤

### 3.1 main.c 修改

在 `Core/Src/main.c` 中添加 Task1 的初始化和主循环调用：

```c
/* USER CODE BEGIN Includes */
#include "Task1_LineTrack.h"
/* USER CODE END Includes */

int main(void)
{
    /* ... HAL 初始化 ... */

    /* USER CODE BEGIN 2 */
    Framework_Init();            // ① 先初始化所有模块

    Task1_LineTrack_Init();      // ② 配置并启动巡线模式
    /* USER CODE END 2 */

    /* USER CODE BEGIN WHILE */
    while (1)
    {
        /* USER CODE BEGIN 3 */
        Task1_LineTrack_Loop();  // ③ 状态监控与调试输出
        /* USER CODE END 3 */
    }
    /* USER CODE END WHILE */
}
```

### 3.2 初始化顺序要求

```
SystemClock_Config()
  → MX_GPIO_Init()
    → MX_DMA_Init()
      → MX_I2C1_Init()
        → MX_TIM1_Init()  (编码器模式)
          → MX_TIM2_Init()  (1ms 基时)
            → MX_TIM3_Init()  (PWM 电机)
              → MX_TIM8_Init()  (编码器模式)
                → MX_USART1_Init()
                  → Framework_Init()    ← 统一模块初始化
                    → Task1_LineTrack_Init()  ← 配置并启动循迹
```

## 四、参数调优

### 4.1 关键参数及默认值

在 [Task1_LineTrack.c](Application/Src/TaskProgram/Task1_LineTrack.c) 中定义：

| 参数 | 默认值 | 说明 | 调优方向 |
|------|--------|------|---------|
| `TASK1_BASE_PWM` | 400 | 直线循迹基准速度 | 太小不走/太大冲出跑道 |
| `TASK1_K_LINE` | 100 | 偏差→差速增益 | 太小纠偏弱/太大会振荡 |
| `TASK1_TURN_PWM` | 400 | 转弯基准 PWM | 太小转不动/太大过冲 |
| `TASK1_ADJUST_DISTANCE_MM` | 60 | 微调前进距离 | 传感器到轮轴中心距离 |
| `TASK1_INTERSECTION_THRESHOLD` | 3 | 路口确认次数 | 太小误检/太大漏检 |

### 4.2 调参顺序

1. **先调基准速度** — 调整 `base_pwm` 使小车能稳定前进 (建议 300~600)
2. **再调纠偏增益** — 调整 `k_line` 使小车能跟上黑线但不振荡 (建议 50~200)
3. **调转弯速度** — 调整 `turn_pwm` 使 90° 转弯干净利落 (建议 300~600)
4. **调微调距离** — 测量传感器安装位置到轮轴的实际距离，填入 `adjust_distance_mm`
5. **调路口阈值** — 如果误检增加阈值，漏检减少阈值

### 4.3 灰度权重校准

8 路传感器默认权重在 [MoveControl.c](Framework/Src/MoveControl.c) 中：

```c
DEFAULT_LINE_W0 = -2.0f  // 通道0 (最右侧) → 剧烈左转
DEFAULT_LINE_W1 = -1.0f   // 通道1
DEFAULT_LINE_W2 = -0.30f  // 通道2
DEFAULT_LINE_W3 = -0.10f  // 通道3 (中心偏右)
DEFAULT_LINE_W4 =  0.10f  // 通道4 (中心偏左)
DEFAULT_LINE_W5 =  0.30f  // 通道5
DEFAULT_LINE_W6 =  1.0f   // 通道6
DEFAULT_LINE_W7 =  2.0f  // 通道7 (最左侧) → 剧烈右转
```

可通过 Vofa+ 上位机实时调整：`ctrl.w_line_0` ~ `ctrl.w_line_7`

## 五、调试输出

### 5.1 串口输出格式

通过 UART1 (PA9/PA10, 115200bps) 输出调试信息：

**启动时：**
```
=== Task1: Square Border Track Start ===
  Edges: 4, BasePWM: 400, KLine: 100, TurnPWM: 400
```

**运行中 (每 500ms)：**
```
[Task1] Edge:1/4 State:FOLLOWING LT:2.5 CH:0x18 LPWM:450 RPWM:350
```

字段说明：
- `Edge` — 当前第几条边 (1~4)
- `State` — 巡线子状态 (FOLLOWING/FWD_ADJUST/TURNING/EDGE_DONE)
- `LT` — 当前 LineTurn 值 (偏差加权和)
- `CH` — 8 路传感器通道位图 (十六进制)
- `LPWM/RPWM` — 当前左右轮 PWM 输出

**完成时：**
```
=== Task1: COMPLETE! 4 edges tracked ===
```

### 5.2 Vofa+ FireWater 遥测

可在 Vofa+ 中实时查看以下变量：
- `ctrl.line_turn` — LineTurn 偏差值
- `ctrl.line_left_pwm` / `ctrl.line_right_pwm` — 左右 PWM
- `ctrl.line_ch_bits` — 通道位图
- `ctrl.edge_count` — 已完成边数
- `ctrl.line_state` — 当前子状态

## 六、常见问题排查

### 小车不走直线

1. 检查左右轮编码器极性：`Encoder_Constructor` 的 `polarity` 参数
2. 检查灰度传感器是否有通道卡死 (串口观察 CH 位图)
3. 增大 `k_line` 增强纠偏力度

### 路口不触发

1. 检查路口处是否有足够的黑色横线宽度 (>20mm)
2. 降低 `intersection_threshold` (当前默认 3)
3. 串口观察路口时 CH 位图是否 >= 6 路检测到黑线
4. 检查灰度传感器安装高度 (建议距离地面 1~3cm)

### 转弯角度不准

1. 检查 MPU6050 是否正常工作 (串口确认陀螺仪 ID=0x68)
2. 调整 `turn_tolerance` (默认 ±3°)
3. 增大 `turn_kp` (默认 20，PWM/°) 增强转弯力度
4. 每次转弯后 Yaw 自动清零，防止零漂累积

### 转弯后找不到线

1. 调整 `adjust_distance_mm` — 传感器到轮轴距离需准确测量
2. 检查转弯后车身是否大致对准下一段黑线
3. 如果转弯后偏离较大，尝试增大转弯 PWM 或调整微调前进距离

### 跑出跑道

1. 降低 `base_pwm` (速度太快来不及纠偏)
2. 增大 `k_line` (增强纠偏)
3. 检查灰度传感器采样频率 (应为 500Hz, 2ms 周期)
