一、概述

STM32F407 拥有多达 14 个定时器，分为高级定时器、通用定时器和基本定时器三大类。每个定时器的多个通道（CH1~CH4）共享同一个计数器 (CNT) 和自动重装载寄存器 (ARR)，但每个通道拥有自己独立的捕获/比较寄存器 (CCRx)，这使得不同通道可以在同一时基下实现不同的输出/输入功能。

核心理解：一个定时器就像一个钟表，CNT 是指针，ARR 是表盘刻度范围，而每个通道（CHx）就像独立的闹钟，各自可以设置不同的响铃时间（CCRx）。它们共享同一个"时间"，但各自独立地触发事件。

三、定时器通道关系深度解析

3.1 共享资源 vs 独立资源

资源 是否共享 说明
CNT (计数器) ✅ 所有通道共享 所有通道共用同一个计数器值，这是通道之间唯一"强制关联"的部分
ARR (自动重装载) ✅ 所有通道共享 所有通道的 PWM 周期/溢出周期由同一个 ARR 决定
PSC (预分频器) ✅ 所有通道共享 所有通道的时钟频率由同一个 PSC 决定
CCRx (捕获/比较值) ❌ 每个通道独立 关键独立资源 — 每个通道有自己的 CCR，决定了各自的占空比/比较值
CCER (捕获/比较使能) ❌ 每个通道独立位 可独立使能/禁能每个通道的输出或输入
CCMRx (模式配置) 部分独立 每个通道的输入/输出模式可在同一寄存器中独立配置
DIER (中断/DMA) 每个通道独立位 可独立使能每个通道的中断或 DMA 请求
输出引脚 ❌ 完全独立 各有独立的 GPIO 引脚（如 PA0=TIM2_CH1, PA1=TIM2_CH2）

3.2 通道关系总结

结论：同一定时器的不同通道是"部分关联、部分独立"的关系

  • 关联部分：所有通道共享同一个 CNT、ARR、PSC — 即它们有相同的时基和PWM 周期。
  • 独立部分：每个通道有自己独立的 CCRx、输出极性、使能位 — 即它们可以有不同的占空比、不同的模式、不同的输出状态。
  • 一个定时器内的不同通道可以同时工作在完全不同的模式下。例如：TIM2_CH1 做 PWM 输出，TIM2_CH2 做输入捕获，TIM2_CH3 做输出比较，TIM2_CH4 做单脉冲模式。

3.3 常见误区澄清

❌ 误区 1：同一定时器的通道必须工作在相同模式。
✅ 事实：每个通道的 CCMRx 寄存器可以独立配置。CH1 可为 PWM 模式，CH2 可为输入捕获模式，互不干扰。

❌ 误区 2：CH1 和 CH2 的 PWM 输出是互补（关联）的。
✅ 事实：在通用定时器（TIM2~TIM5、TIM9~TIM14）中，CH1 和 CH2 的 PWM 输出完全独立，只是周期相同但占空比可随意设置。只有高级定时器（TIM1、TIM8）才有真正的互补输出（CH1 与 CH1N）。

❌ 误区 3：修改一个通道的配置会影响其他通道。
✅ 事实：只要不改 ARR 和 PSC，只修改某个通道的 CCRx 或 CCER 位，完全不会影响其他通道的工作。

4.3 高级定时器互补输出（TIM1/TIM8）

高级定时器除了 CH1~CH4 外，还有 CH1N、CH2N、CH3N 三个互补输出通道：

  • CH1 与 CH1N — 互补关系（电平相反，带死区）
  • CH2 与 CH2N — 互补关系（电平相反，带死区）
  • CH3 与 CH3N — 互补关系（电平相反，带死区）
  • CH4 — 无互补输出（单端）
⚠️ 关于死区：
在互补 PWM 中，CH1 从高变低后，CH1N 需要等待一段"死区时间"才能变为高电平，反之亦然。这是为了防止上下桥臂同时导通导致短路。死区时间由 TIMx_BDTR.DTG 寄存器设置。

五、输出比较模式

在输出比较模式下，每个通道更加独立。每个通道可以独立设置：

  • 比较值 (CCRx) — 当 CNT 匹配 CCRx 时触发事件
  • 输出动作 — 匹配时可选择：置高、置低、翻转、强制高、强制低
  • 中断/DMA — 匹配时可独立产生中断或 DMA 请求
输出比较模式下通道完全独立：CH1 匹配时翻转 GPIO，CH2 匹配时置高 GPIO，CH3 匹配时产生中断不改变 GPIO，CH4 匹配时触发 DMA。所有通道共享同一计数器，但各自的行为完全独立。

六、输入捕获模式

输入捕获模式下，每个通道捕获外部引脚上的脉冲：

  • 每个通道使用独立的 GPIO 引脚捕获外部信号
  • 当检测到指定边沿（上升沿/下降沿/双边沿）时，将当前 CNT 值锁存到该通道的 CCRx
  • 可独立配置每个通道的捕获边沿、预分频、滤波器
  • 常用于测量脉冲宽度、频率、周期等

PWM 输入模式（特殊用法）

这是输入捕获的一种特殊用法，占用 两个通道 来测量一个 PWM 信号的频率和占空比：

  • CH1 捕获周期（连续两个上升沿的 CNT 差值）
  • CH2 捕获脉宽（上升沿到下降沿的 CNT 差值）
  • 两个通道配合工作，但这是通过硬件自动完成的，不需要软件干预
注意：PWM 输入模式需要将 CH1 和 CH2 配置为关联模式（通过 CCMR1.TI1_Select 和 ICx_Select），此时 CH1 的信号会间接连接到 CH2 的捕获电路。这与自由独立的输入捕获不同。

七、编码器模式

编码器模式使用 CH1 和 CH2 两个通道 配合工作：

  • CH1 (TI1) — 连接编码器的 A 相
  • CH2 (TI2) — 连接编码器的 B 相
  • 两路信号配合判断旋转方向和速度
  • CNT 根据两路信号的相位关系自动递增/递减
编码器模式下 CH1 和 CH2 高度关联：两者必须同时工作，缺一不可。编码器模式占用整个定时器，此时 CH3 和 CH4 仍可作为独立通道使用（但不能与编码器模式冲突）。

八、定时器用法指南

8.1 基本时基（定时中断）

使用基本定时器 TIM6/TIM7 或任意通用/高级定时器实现固定间隔中断：

// 计算 ARR 和 PSC 的公式
// TIMx_CLK = 定时器时钟 (如 APB1=84MHz, APB2=168MHz)
// 定时频率 = TIMx_CLK / (PSC+1) / (ARR+1)
// 以 1kHz (1ms 中断) 为例，TIM2 在 APB1=84MHz 下：
PSC = 83;     // 84MHz / (83+1) = 1MHz (1µs 计数一次)
ARR = 999;    // 1MHz / (999+1) = 1kHz (1ms 中断)

8.2 多通道 PWM 输出

例如需要两路不同占空比的 PWM，使用同一个定时器的 CH1 和 CH2：

// 使用 TIM3 输出两路不同占空比的 PWM
// 频率：20kHz, CH1 占空比 30%, CH2 占空比 60%
// TIM3 在 APB1=84MHz 下

void MX_TIM3_Init(void)
{
    TIM_HandleTypeDef htim3;
    
    // 1. 配置时基（公共部分）
    htim3.Instance = TIM3;
    htim3.Init.Prescaler = 83;          // 84MHz/84 = 1MHz
    htim3.Init.Period = 49;             // 1MHz/50 = 20kHz
    htim3.Init.CounterMode = TIM_COUNTERMODE_UP;
    HAL_TIM_PWM_Init(&htim3);
    
    // 2. 配置通道 1（占空比 30%）
    TIM_OC_InitTypeDef sConfigOC;
    sConfigOC.OCMode = TIM_OCMODE_PWM1;
    sConfigOC.Pulse = 15;               // CCR1 = 15, 15/50 = 30%
    sConfigOC.OCPolarity = TIM_OCPOLARITY_HIGH;
    sConfigOC.OCFastMode = TIM_OCFAST_DISABLE;
    HAL_TIM_PWM_ConfigChannel(&htim3, &sConfigOC, TIM_CHANNEL_1);
    
    // 3. 配置通道 2（占空比 60%）
    sConfigOC.Pulse = 30;               // CCR2 = 30, 30/50 = 60%
    HAL_TIM_PWM_ConfigChannel(&htim3, &sConfigOC, TIM_CHANNEL_2);
    
    // 4. 启动所有通道
    HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
    HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_2);
    
    // ✅ CH1 输出 20kHz, 30% 占空比的 PWM
    // ✅ CH2 输出 20kHz, 60% 占空比的 PWM
    // ✅ CH3 和 CH4 未配置，可作为普通 GPIO
}

8.3 一个定时器同时实现多种功能

// TIM2: CH1=PWM输出, CH2=输入捕获, CH3=输出比较
// 所有通道共享 84MHz 时基，但功能完全不同

// 步骤 1：配置时基
htim2.Init.Prescaler = 83;      // 1MHz
htim2.Init.Period = 65535;      // 16位自动重装载
HAL_TIM_Base_Init(&htim2);

// 步骤 2：CH1 - PWM 输出
sConfigOC.OCMode = TIM_OCMODE_PWM1;
sConfigOC.Pulse = 32768;        // 50% 占空比
HAL_TIM_PWM_ConfigChannel(&htim2, &sConfigOC, TIM_CHANNEL_1);
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);

// 步骤 3：CH2 - 输入捕获（测量外部脉冲宽度）
TIM_IC_InitTypeDef sConfigIC;
sConfigIC.ICPolarity = TIM_INPUTCHANNELPOLARITY_RISING;
sConfigIC.ICSelection = TIM_ICSELECTION_DIRECTTI;
sConfigIC.ICPrescaler = TIM_ICPSC_DIV1;
sConfigIC.ICFilter = 0;
HAL_TIM_IC_ConfigChannel(&htim2, &sConfigIC, TIM_CHANNEL_2);
HAL_TIM_IC_Start_IT(&htim2, TIM_CHANNEL_2);

// 步骤 4：CH3 - 输出比较（CNT到达CCR3时翻转GPIO）
sConfigOC.OCMode = TIM_OCMODE_TOGGLE;
sConfigOC.Pulse = 10000;
HAL_TIM_OC_ConfigChannel(&htim2, &sConfigOC, TIM_CHANNEL_3);
HAL_TIM_OC_Start(&htim2, TIM_CHANNEL_3);

8.4 带死区的互补 PWM（TIM1/TIM8）

// TIM1 CH1 + CH1N 互补输出，带 100ns 死区
// TIM1 在 APB2=168MHz 下

htim1.Instance = TIM1;
htim1.Init.Prescaler = 0;               // 168MHz
htim1.Init.Period = 1679;               // 168MHz/1680 = 100kHz PWM
HAL_TIM_PWM_Init(&htim1);

// 死区时间配置 (BDTR 寄存器)
// DTG[7:0] = 17, t_dts = 1/168MHz = 5.95ns
// 死区 = DTG * t_dts = 17 * 5.95ns ≈ 101ns
HAL_TIMEx_ConfigBreakDeadTime(&htim1, &sBreakDeadTimeConfig);

sConfigOC.OCMode = TIM_OCMODE_PWM1;
sConfigOC.Pulse = 840;                  // 50% 占空比
sConfigOC.OCPolarity = TIM_OCPOLARITY_HIGH;
sConfigOC.OCNPolarity = TIM_OCNPOLARITY_HIGH;
sConfigOC.OCIdleState = TIM_OCIDLESTATE_RESET;
sConfigOC.OCNIdleState = TIM_OCNIDLESTATE_RESET;

HAL_TIM_PWM_ConfigChannel(&htim1, &sConfigOC, TIM_CHANNEL_1);
HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1);
HAL_TIMEx_PWMN_Start(&htim1, TIM_CHANNEL_1);  // 启动互补输出

8.5 定时器同步与级联

STM32F407 的定时器可以通过内部触发信号实现级联（如 TIM2 可通过 TRGO 触发 TIM3 启动）：

  • 一个定时器作为主定时器 — 配置 TIMx_CR2.MMS 选择触发输出 (TRGO) 信号
  • 另一个定时器作为从定时器 — 配置 TIMx_SMCR.SMS 选择从模式，TS 选择触发源
  • 常用于实现长定时（两个 16 位定时器级联成 32 位）、精确相位控制等

九、注意事项与常见陷阱

9.1 定时器时钟源（APB1 vs APB2）

关键注意：APB1 (低速总线) 上的定时器最大时钟为 84MHz，APB2 (高速总线) 为 168MHz。
APB1 定时器：TIM2~TIM7、TIM12~TIM14
APB2 定时器：TIM1、TIM8、TIM9~TIM11

预分频器注意事项：如果 APBx 分频系数 ≠ 1，则定时器时钟 = APBx 时钟 × 2。例如 APB1 配置为 42MHz (分频系数=2) 时，定时器时钟自动变为 84MHz。

9.2 16 位溢出问题

ARR 和 CCR 的位宽限制：
  • 16 位定时器（大部分定时器）：ARR 和 CCR 范围为 0~65535
  • 32 位定时器（TIM2、TIM5）：ARR 和 CCR 范围为 0~4294967295
  • 使用 16 位定时器产生低频信号时，可能需要配合较大的 PSC，例如 1Hz 输出：PSC=8399（8400-1），ARR=9999（10000-1），84MHz/8400/10000 = 1Hz
  • 如果 PSC 也达到上限（65535），低频仍不够低时，考虑改用 32 位定时器或级联

9.3 预装载与影子寄存器

影子寄存器概念：
ARR 和 CCRx 都有"预装载寄存器"和"影子寄存器"两套。
  • 写入 ARR 或 CCRx 时，实际写入的是预装载寄存器
  • 预装载寄存器的值只在更新事件 (UEV) 时才会传送到影子寄存器（实际工作的寄存器）
  • 这样可以避免在计数过程中修改 ARR/CCR 导致 PWM 周期/占空比出现异常
  • CCMRx.OCxPE 位使能/禁能 CCR 的预装载功能（建议始终使能）
  • CR1.ARPE 位使能/禁能 ARR 的预装载功能（建议始终使能）

9.4 更新事件 (UEV) 与计数器清零

当 CNT 达到 ARR 时发生更新事件：
  • CNT 清零（向上计数模式）
  • 影子寄存器从预装载寄存器加载新值
  • 可产生更新中断 (UI) 或 DMA 请求
  • 更新事件也可通过软件设置 CR1.UG 位强制产生
  • 如果 CR1.UDIS = 1，更新事件被禁能，ARR 的预装载到影子的传输不会发生
  • 如果 CR1.URS = 1，只有计数器溢出才产生更新事件（软件 UG 不触发 UEV）

9.5 刹车功能（高级定时器）

刹车输入 (Break Input) 用于电机控制安全：
  • 当刹车信号有效时，PWM 输出立即进入安全状态（由 BDTR.AOE、BDTR.MOE 控制）
  • 刹车信号可以来自：外部引脚 (BKIN)、比较器输出、系统故障等
  • 刹车输入支持可编程极性、滤波器和自动恢复
  • 在电机驱动应用中，务必正确配置刹车功能以防止功率管烧毁

9.6 中断与 DMA 注意事项

  • 多个通道共享同一中断向量：一个定时器的所有通道中断共享同一个中断服务函数 (ISR)，需要在 ISR 中通过检查状态寄存器 (SR) 来区分是哪个通道触发的
  • 中断频率过高：PWM 频率很高时（如 100kHz 以上），每个周期触发中断可能导致 CPU 负载过高，考虑使用 DMA
  • DMA 突发传输：可以通过 DMA 同时更新多个 CCR 值，实现多通道同步改变占空比

9.7 GPIO 复用功能配置

定时器通道输出必须正确配置 GPIO 复用功能：
  • 以 TIM2_CH1 为例，其在 PA0 引脚输出，需要将 PA0 配置为 AF1（复用功能 1）
  • 不同定时器的通道可能映射到不同 GPIO 引脚，需查阅数据手册的"Alternate Function Mapping"表
  • 输出 PWM 时 GPIO 速度建议设为 High 或 Very High
  • 输入捕获时 GPIO 可配置为浮空输入或上拉/下拉输入

9.8 一键清零与重装（单脉冲模式）

单脉冲模式 (OPM)：
设置 CR1.OPM = 1，定时器在发生第一个更新事件后自动停止。配合触发输入（如外部引脚），可以实现对外部事件的单脉冲响应。常用于：精确延时触发、可控硅控制等。

9.9 32 位定时器的优势

TIM2 和 TIM5 是 32 位定时器：
它们的 CNT、ARR、CCR 都是 32 位宽。在需要：
  • 极低频率：如 0.1Hz（10 秒周期）
  • 高精度长时间测量：如精确到微秒的秒级脉冲宽度测量
  • 长时间定时：无需级联即可实现长达数分钟的定时
应优先使用 TIM2/TIM5。

十、经典应用场景代码示例

10.1 呼吸灯（双通道独立 PWM）

// TIM3_CH1 (PA6) 和 TIM3_CH2 (PA7) 两个 LED 独立呼吸
// 两个 LED 以不同速度渐变，互不干扰

void breathing_led_demo(void)
{
    static uint16_t duty1 = 0, duty2 = 500;
    static int8_t dir1 = 1, dir2 = -1;
    
    // CH1 呼吸
    if (dir1 > 0 && duty1 >= 999) dir1 = -1;
    if (dir1 < 0 && duty1 <= 0)   dir1 = 1;
    duty1 += dir1 * 5;
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, duty1);
    
    // CH2 呼吸（方向相反，实现交替呼吸效果）
    if (dir2 > 0 && duty2 >= 999) dir2 = -1;
    if (dir2 < 0 && duty2 <= 0)   dir2 = 1;
    duty2 += dir2 * 3;
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_2, duty2);
    
    HAL_Delay(10);
}

10.2 输入捕获测量频率

// 使用 TIM4_CH1 (PB6) 测量外部信号频率
// 捕获原理：测量连续两个上升沿之间的时间差

volatile uint32_t cap1 = 0, cap2 = 0;
volatile uint8_t cap_done = 0;

void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == TIM4 && htim->Channel == HAL_TIM_ACTIVE_CHANNEL_1)
    {
        if (cap_done == 0) {
            cap1 = HAL_TIM_ReadCapturedValue(htim, TIM_CHANNEL_1);
            cap_done = 1;
        } else {
            cap2 = HAL_TIM_ReadCapturedValue(htim, TIM_CHANNEL_1);
            if (cap2 > cap1) {
                uint32_t period = cap2 - cap1;
                // 频率 = 定时器时钟 / (PSC+1) / period
                // 此处 PSC=83, Tclk=84MHz → Tcnt=1µs
                // frequency = 1,000,000 / period (Hz)
            }
            cap_done = 0;
        }
    }
}

void encoder_init(void)
{
    TIM_Encoder_InitTypeDef sEncoder;
    
    htim3.Instance = TIM3;
    htim3.Init.Prescaler = 0;
    htim3.Init.Period = 65535;
    htim3.Init.CounterMode = TIM_COUNTERMODE_UP;
    
    sEncoder.EncoderMode = TIM_ENCODERMODE_TI12;  // TI1+TI2 双边缘
    sEncoder.IC1Polarity = TIM_ICPOLARITY_RISING;
    sEncoder.IC1Selection = TIM_ICSELECTION_DIRECTTI;
    sEncoder.IC1Prescaler = TIM_ICPSC_DIV1;
    sEncoder.IC1Filter = 10;
    sEncoder.IC2Polarity = TIM_ICPOLARITY_RISING;
    sEncoder.IC2Selection = TIM_ICSELECTION_DIRECTTI;
    sEncoder.IC2Prescaler = TIM_ICPSC_DIV1;
    sEncoder.IC2Filter = 10;
    
    HAL_TIM_Encoder_Init(&htim3, &sEncoder);
    HAL_TIM_Encoder_Start(&htim3, TIM_CHANNEL_ALL);
}
