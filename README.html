F407VET6_Templet

这个项目是一个基于F407VET6的模板项目，用于快速搭建电赛F407VET6环境。

系统架构（System Architecture）

分为三层，分别是：

  • 设备层（Device Layer）
  • 框架层（Framework Layer）
  • 应用层（Application Layer）

该系统以面向对象的方式组织，每个设备都有一个对应的类，通过继承和组合的方式实现功能。

1. 设备层（Device Layer）

分为三个部分：

  1. 设备的类（Device Class）
  2. 调试外设（Debug Peripheral）
  3. 滤波算法（Filter Algorithm）
📋 概述

设备层是整个系统的基础硬件抽象层，负责对各类硬件设备进行封装和管理。通过将设备抽象为类，提供统一的接口供上层调用，实现了代码的模块化和可复用性。

1. 设备的类（Device Class）

主干是三大基类：

Modules

引申的子类有：

  • LED — 指示灯控制
  • KEY — 按键输入
  • OLED — OLED 显示屏驱动
  • BUZZER — 蜂鸣器
📝 Modules 说明

Modules 基类封装了常见的输出/输入模块设备，提供统一的初始化与控制接口。各子类继承基类并实现具体的硬件操作逻辑。

Sensors

引申的子类有：

  • Encoder（编码器） — 用于电机速度/位置检测
  • Gyro（陀螺仪）— MPU6050 — 6 轴惯性测量单元（加速度计 + 陀螺仪）
  • LineSensor（灰度循迹模块） — 8 路灰度传感器，用于循迹
  • VisionSensor（视觉模块）— K230
    这里使用 Python 实现，并使用 API 或者 UART 实现通信
📝 Sensors 说明

Sensors 基类抽象了各类传感器的数据采集与处理接口。各子类实现具体的传感器驱动、数据校准与滤波逻辑。

Motors

引申的子类有：

  • DCMotor（直流电机） — 配合 TB6612 驱动，支持 PWM 调速
  • StepMotor（步进电机） — 配合 ULN2003 驱动，支持 4/8 步时序
  • Servo — 舵机控制
📝 Motors 说明

Motors 基类封装了各类电机的控制接口，包括速度/位置控制、启停等。各子类实现具体的驱动时序与控制算法。

2. 调试外设（Debug Peripheral）

分为四类：

  • UART 调试 — 串口打印调试信息
  • OLED 打印 — OLED 屏幕实时显示数据
  • SPI 调试 — SPI 总线调试
  • I2C 调试 — I2C 总线调试

3. 滤波算法（Filter Algorithm）

主要是 PID 算法和传感器滤波算法。

  • PID 算法 — 用于电机闭环控制（速度环、位置环）
  • 传感器滤波算法 — 用于对传感器原始数据进行平滑去噪（如均值滤波、卡尔曼滤波等）

2. 框架层（Framework Layer）

分为多个系统：

1. 通信系统（Communication System）

主要是 UART 通信系统，用于与 PC 端以及 K230 进行通信。

2. 运动控制系统（Motion Control System）

主要是 PID 控制器，用于控制电机的运动。

3. 状态机系统（State Machine System）

主要是状态机，用于控制系统的运行状态。

3. 应用层（Application Layer）

1. 主程序（Main Program）

主要是系统的主程序，用于初始化系统、运行状态机、与 PC 端进行通信等。

2. 中断回调函数（Interrupt Callback Function）

主要是处理中断的函数，用于响应外部事件，如按键按下、编码器旋转等。

主要是系统的核心，用于实现系统的功能。
