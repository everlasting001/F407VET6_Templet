# 快速开始：为 Claude 接入硬件知识库

## 3 分钟快速设置

### 步骤 1：准备你的硬件文件

收集以下文件（不需要全部，优先级从高到低）：

**必备（强烈推荐）**：
- [ ] STM32F407VET6 参考手册 (RM0090) — [下载](https://www.st.com)
- [ ] 电机驱动板原理图 PDF
- [ ] 电机型号数据手册

**可选但有帮助**：
- [ ] 驱动 IC 数据手册（如 L298N、DRV8833 等）
- [ ] PCB 布局图
- [ ] 物料清单 (BOM)

### 步骤 2：放到正确的文件夹

```bash
# 打开这个目录
.claude/docs/

# 创建子文件夹（如不存在）
mkdir -p .claude/docs/datasheets
mkdir -p .claude/docs/schematics
mkdir -p .claude/docs/pcb

# 放置文件
# 数据手册 → datasheets/
# 原理图   → schematics/
# PCB 文件 → pcb/
```

### 步骤 3：更新索引（可选但推荐）

编辑 `.claude/docs/README.md`，填写你的硬件信息：

```markdown
### 电源管理
| 参数 | 值 | 文件 |
|------|-----|------|
| 输入电压 | 12V | power-supply.pdf |
| 稳压输出 | 3.3V / 5V | power-supply.pdf |

### 电机驱动
| 参数 | 值 | 文件 |
|------|-----|------|
| 驱动型号 | L298N | driver-l298n.pdf |
| 最大电流 | 2A per channel | driver-l298n.pdf |
| 电机型号 | TT-6V | motor-tt6v.pdf |
```

### 步骤 4：完成！

现在你可以告诉我：
```
"我的电机是 TT-6V，驱动板是 L298N"
```

我会自动查找你放在 `.claude/docs/` 中的相关文档，并在回答时参考具体的规格和原理图。

A: 不会。我会在需要时读取，不会影响项目编译。

- 参数调整 ✓
