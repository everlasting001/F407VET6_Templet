### 第五步：电机驱动板接口

#### H 桥输入信号
```
STM32F407          驱动板
├─ PA___ (DIR1) ──→ IN1/IN3
├─ PA___ (DIR2) ──→ IN2/IN4
├─ PA___ (PWM)  ──→ ENA/ENB
└─ GND ───────────→ GND
```

**检查清单**：
- [ ] 信号接线正确对应原理图
- [ ] 无接反（会导致电机反向）
- [ ] GND 连接可靠
- [ ] 接头接触良好（无虚焊）

#### H 桥输出到电机
```
驱动板         电机
├─ OUT1 ──────→ M+
├─ OUT2 ──────→ M-
└─ GND ────────→ GND (共地)
```

**检查清单**：
- [ ] 电机接线对应正确
- [ ] 无反接（会导致反向旋转）
- [ ] 电流路径完整

## 问题诊断树

```
电机不转
├─ 电源检查
│  ├─ 主电源正常？ (是 → 下一步, 否 → 检查电源)
│  └─ 驱动板供电灯亮？ (是 → 下一步, 否 → 检查驱动板电源)
│
├─ 信号检查
│  ├─ GPIO 电平正确？ (示波器或万用表测)
│  ├─ PWM 信号正常？ (频率、占空比)
│  └─ 方向控制逻辑对？ (检查 IN1/IN2 组合)
│
├─ 驱动板检查
│  ├─ 驱动板 LED 亮？ (是 → 下一步, 否 → 驱动板故障)
│  └─ 驱动芯片发热？ (过热 → 短路, 正常 → 下一步)
│
└─ 电机检查
   ├─ 电机接线对？ (反接 → 反向)
   └─ 电机坏？ (手摇转？ 无阻力 → 坏)

烧毁驱动芯片
├─ 反电动势未管理？ (检查续流二极管)
├─ H 桥贯穿？ (检查死区时间和控制逻辑)
└─ 过流？ (检查电流限制和过载保护)
```
