# 原理图与PCB阅读指南

## 原理图阅读基础

### 符号识别

| 符号 | 名称 | 作用 | 检查项 |
|------|------|------|--------|
| 🔌 IC (方形多脚) | 集成电路 | 信号处理、驱动等 | 引脚号、电压等级、使能信号 |
| ◯ 圆形 + 直线 | 晶体管 | 放大、开关 | 基极/栅极偏置、饱和条件 |
| △ | 运放 | 信号条件 | 反馈网络、增益、稳定性 |
| —/— | 电阻 | 限流、分压 | 阻值、功率、精度等级 |
| —||— | 电容 | 耦合、滤波 | 容值、耐压、ESR |
| ⟲ | 电感 | 滤波、储能 | 感值、饱和电流、Q值 |
| ⚡ | LED | 指示灯 | 工作电流、正向压降、颜色 |
| 🔌 | 连接器 | 接口 | 引脚定义、额定电流、信号类型 |

### 原理图阅读步骤

**第一步：识别主要功能块**
- 电源部分：输入 → 稳压 → 输出
- 信号处理部分：输入信号 → 放大/滤波 → 输出
- 驱动部分：控制信号 → 驱动芯片 → 负载
- 反馈部分：传感器 → 信号调理 → MCU

**第二步：追踪关键信号路径**
- 从 MCU 引脚出发，追踪到最终负载
- 标注每个节点的电压、频率、幅度
- 检查驱动能力是否匹配

**第三步：验证电气特性**
- 电压等级是否正确（3.3V vs 5V MCU）
- 阻抗匹配（SPI、I2C 等总线）
- 上拉/下拉电阻配置
- 去耦电容放置

**第四步：检查电源完整性**
- 每个 IC 都有 VCC 和 GND 接线吗？
- 去耦电容靠近 IC 电源管脚吗？
- 返回路径完整吗？

## 电机驱动电路分析

### 典型电机驱动拓扑

#### H桥驱动（常见电机驱动）
```
        +VCC
        |
    Q1  |  Q3
    ─┴─ + ─┴─
    |   |   |
    +───●───+
    |   |   |
    ─┬─ + ─┬─
    Q2  |  Q4
        |
    Motor（M+/M-）
        |
       GND
```

**检查项**：
- [ ] 四个 MOSFET 栅极是否有合适的驱动波形（不能同时导通 Q1/Q2 或 Q3/Q4）
- [ ] 是否有自举电路为高侧 MOS 栅极供电？
- [ ] 是否有死区时间防止贯穿电流？
- [ ] 反向二极管是否配置正确？

#### PWM 调速
```
MCU PWM ──→ [驱动芯片] ──→ Q1/Q2/Q3/Q4 ──→ 电机速度控制
            (死区生成)
```

**关键参数**：
- PWM 频率（通常 1-20 kHz）
- PWM 分辨率（8/10/12/16 位）
- 死区时间（防止 Q1 和 Q2 同时导通）

### 电机反电动势管理

**问题**：电机断电时，电感释放的反电动势会损坏驱动电路

**解决方案**：
1. **续流二极管**（Freewheeling Diode）
   - 放在 MOSFET 对角线
   - 允许反电动势通过安全路径流动

2. **TVS 二极管或齐纳二极管**
   - 保护驱动芯片输入
   - 限制峰值电压

## PCB 布局检查

### 关键信号完整性

**高速信号（>1 MHz）**：
- [ ] 差分对等长布线
- [ ] 特征阻抗控制（通常 50Ω）
- [ ] 避免过孔星形接地

**电源完整性**：
- [ ] 电源层连续分布
- [ ] 去耦电容尽量靠近 IC
- [ ] 通孔距离 < 3mm

**EMI 控制**：
- [ ] 高功率信号与敏感信号分离
- [ ] 地返回路径完整
- [ ] 屏蔽层（如有）接地

### 热管理

- [ ] 大功率器件是否有散热焊盘？
- [ ] 是否有散热孔连接内层？
- [ ] 电流路径是否尽量短以减少 I²R 损耗？

### 机械完整性

- [ ] 连接器引脚排列正确吗？
- [ ] 高电流接线是否加粗（铜厚度/宽度）？
- [ ] 是否有标丝孔或定位孔？

## 从原理图到代码的映射

### 示例：GPIO 控制电机

**原理图**：
```
STM32F407 PA5 ──→ [100Ω] ──→ Q1 栅极 ──→ H桥上臂
            PA6 ──→ [100Ω] ──→ Q2 栅极 ──→ H桥下臂
```

**代码实现**：
```c
// 初始化（对应原理图中的上拉/下拉、速度设置）
GPIO_InitStruct.Pin = GPIO_PIN_5 | GPIO_PIN_6;
GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_HIGH;  // 快速开关
GPIO_InitStruct.Pull = GPIO_NOPULL;
HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

// 控制电机正转
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);   // Q1 开启
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_6, GPIO_PIN_RESET); // Q2 关闭
```

### 示例：PWM 速度控制

**原理图**：
```
STM32F407 PA0 (TIM2_CH1) ──→ [PWM 驱动] ──→ H桥速度控制
```

**代码实现**：
```c
// 配置 PWM（在 CubeMX 或手动配置）
TIM_HandleTypeDef htim2;
// 配置 PWM 频率、分辨率等

// 启动 PWM
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);

// 设置占空比（0-100%）
__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, pwm_value);
```

## 数据手册查阅速查

### STM32F407
- **GPIO 相关** → 章节 8（GPIO）
- **时钟配置** → 章节 6（RCC）
- **中断** → 章节 11（NVIC）
- **PWM/定时器** → 章节 14-15（TIM）
- **通信接口** → 章节 26-30（UART/SPI/I2C）

### MOSFET 驱动器选型
检查以下参数：
- **逻辑电压** - 与 MCU 输出电压匹配（3.3V 还是 5V）
- **驱动电流** - MOSFET 栅极充放电速度
- **隔离** - 是否需要光耦隔离（高压应用）
- **集成功能** - 死区生成、短路保护等

### 电机驱动芯片 (如 L298N 等)
- **输入电压范围** - 与电源匹配
- **输出电流** - 与电机额定电流匹配
- **热阻** - 计算散热需求
- **控制方式** - PWM 还是逻辑电平？

## 常见硬件问题诊断

| 现象 | 可能原因 | 排查步骤 |
|------|--------|--------|
| 电机不转 | 1. 驱动信号不到位 | 示波器测 PWM/GPIO |
|  | 2. 电源不足 | 检查 VCC 电压 |
|  | 3. H桥贯穿 | 检查死区时间 |
| 电机转但不受控 | 1. 反馈断开 | 检查反馈电路 |
|  | 2. 控制参数错误 | 调整 PWM 频率/分辨率 |
| 烧毁芯片 | 1. 反电动势未管理 | 检查续流二极管 |
|  | 2. 供电不稳定 | 增加去耦电容 |
| 电机异常声响 | 1. PWM 频率太低 | 增加 PWM 频率 |
|  | 2. 电流突波过大 | 增加限流电阻或软启动 |

## 最佳实践

✅ **必做**：
- 始终从电源检查开始
- 用示波器验证关键信号
- 保存原理图的标注版本（涂鸦版）

❌ **禁止**：
- 在没有数据手册的情况下直接焊接
- 忽视功率器件的散热
- 在未保护的情况下连接反电动势路径
