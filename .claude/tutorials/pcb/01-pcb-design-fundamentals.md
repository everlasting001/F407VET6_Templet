# PCB设计入门完全指南（嘉立创EDA）

## 第一部分：PCB设计基础知识

### 什么是PCB？

PCB（Printed Circuit Board，印刷电路板）是电子产品的"骨架"，用于：
- 承载各种电子元器件（IC芯片、电阻、电容、连接器等）
- 通过铜箔布线连接这些元器件，形成电路
- 提供机械支撑和保护

**关键概念**：
- **导电层**：铜箔层，用于信号传输和电源分配
- **绝缘层**：覆铜板的介质，隔离不同层的信号
- **焊盘**：焊接点，焊接元器件引脚
- **过孔**：连接不同层的导孔

### PCB的层构成

| 层名 | 用途 | 说明 |
|------|------|------|
| **顶层（F.Cu）** | 主要器件放置、顶面布线 | 可见、可焊 |
| **底层（B.Cu）** | 底面布线、返回路径 | 通常放返回地 |
| **电源层** | 电源分配（多层板） | 铜铂连续，低阻抗 |
| **地层** | 地返回路径（多层板） | 最大化接地面积 |
| **阻焊层** | 防止焊接桥接 | 保护铜箔，仅露出焊盘 |
| **丝印层** | 器件标号、标记 | 白色字标记 |

**本项目推荐**：
- 电赛项目通常使用 **2层PCB**（顶层+底层）
- 成本低、易于制造、足以满足需求
- 高频/高速项目才需要多层板

### 电气设计的关键原则

#### 1. **地返回路径**
```
好的设计：
+5V ──→ [负载] ──→ GND
    ↑           ↓
    └─ 返回路径（尽量短）

差的设计：
+5V ──→ [负载] ──→ GND (返回路径很长或绕路)
                    ↓
            造成噪声和干扰
```

**规则**：每个电流最短返回地
- 减少环路面积 → 降低噪声
- 减少阻抗 → 更稳定的电源

#### 2. **去耦电容**
**作用**：吸收IC切换时的浪涌电流，稳定电源电压

**规则**：
- 每个IC电源引脚附近放置去耦电容
- 容值：0.1µF（最常用）+ 10µF（大容值）
- 距离：尽量靠近IC电源管脚（< 5mm）

```
供电链：
     +5V ──→ [100µF] ──→ [0.1µF] ──→ IC VCC
                ↓            ↓
              GND          GND (就近)
```

#### 3. **阻抗匹配**
**针对本项目**：
- I2C/SPI总线：不需要严格匹配（速率< 10 MHz）
- 可使用典型阻值的上拉电阻（4.7kΩ）
- PWM/GPIO：普通信号，无需特殊处理

#### 4. **干扰隔离**
```
好的布局：
┌─ 数字电路（高速信号）─┐  ┌─ 电源（5V主）─┐
│ STM32, GPIO驱动      │  │ 电源管理、去耦│
└──────────────────────┘  └──────────────┘
         ||                      ||
     数字地返回路径          电源地返回路径
         ||                      ||
┌─ 模拟电路（敏感信号）─┐
│ 传感器、ADC采样       │
└──────────────────────┘
```

## 第二部分：嘉立创EDA工作流程

### 完整的PCB设计流程

```
1. 原理图设计 (Schematic)
   └─→ 定义元器件、连接方式

2. 项目管理 (Project)
   └─→ 关联原理图文件

3. 封装与库管理 (Library)
   └─→ 关联各元器件的PCB足迹

4. PCB设计 (PCB Layout)
   ├─ 导入网表 (Netlist)
   ├─ 放置元器件 (Placement)
   ├─ 布线 (Routing)
   ├─ 验证 (DFM Check, 可制造性检查)
   └─ 输出 (Output Gerber/钻孔文件)

5. 制造与装配
   └─→ 发送到PCB厂家
```

### 嘉立创EDA的优势

✅ **优点**：
- 免费/低成本，云端库庞大（上万个器件库）
- 集成供应链（嘉立创PCB + 贴片服务）
- 学习曲线平缓，新手友好
- 与嘉立创工厂直接对接，少改版

❌ **局限**：
- 功能不如 Altium / KiCAD 高端
- 云端依赖（需网络）
- 库质量参差不齐

### 入门步骤

#### 步骤1：创建项目
```
文件 → 新建项目 → 输入项目名称 (e.g., "F407_MotorBoard")
```

#### 步骤2：设计原理图（Schematic）
**在原理图编辑器中**：
1. **放置器件**：右侧"库"面板 → 搜索器件（如 STM32F407）→ 放置
2. **绘制连接**：使用"导线工具"连接器件引脚
3. **添加电源/地**：
   - 插入电源符号（+5V、GND等）
   - 连接所有电源引脚到相应符号
4. **标注**：添加标号、注释，便于PCB阶段查看
5. **生成网表**：菜单 → 输出 → 网表，供PCB使用

**原理图的黄金规则**：
- 清晰的逻辑：按功能块排列（电源块、驱动块、MCU块）
- 完整性检查：无浮空引脚、无重复标号
- 元器件库选择：选择"有"PCB封装的库版本（避免后期找不到脚)

#### 步骤3：创建PCB工程
```
文件 → 新建PCB → 关联原理图 → 导入网表
```

#### 步骤4：放置元器件（Placement）

**原则**：
```
┌────────────────────────────────────┐
│         MCU (中心)                  │
│  STM32F407 + 晶振 + 复位电路      │
│                                     │
│ ┌─ 左侧：电源管理                  │
│ │  稳压器、滤波电容              │
│ │                                   │
│ │ ├─ 右侧：驱动电路               │
│ │ │ TB6612、光耦隔离、保护       │
│ │ │                                 │
│ │ └─ 底部：连接器                 │
│ │   马达接口、调试接口、电源接口 │
│ └─ 四周：去耦电容（靠近IC）      │
└────────────────────────────────────┘
```

**关键放置规则**：
1. **MCU 中心放置**：作为主控，其他模块围绕它
2. **信号流向**：左→右（输入→处理→输出）
3. **电源分组**：
   - 5V主电源一侧
   - 3.3V稳压一侧
4. **高频信号远离模拟信号**（避免干扰）
5. **大容值电容靠近MCU（< 10mm）**

**常见错误**：
```
❌ 把所有元件堆在一起
❌ 长的导线跨越整个PCB
❌ 没有为连接器预留空间
❌ 去耦电容放在很远的地方
```

#### 步骤5：布线（Routing）

**嘉立创EDA布线工具**：
- **自动布线**（推荐初学者）：
  ```
  工具 → 自动布线 → 配置布线参数 → 执行
  ```
  参数建议：
  - 导线宽度：12mil（0.3mm，适合一般电流）
  - 最小间距：8mil（0.2mm）
  - 线间距离：8mil（嘉立创标准）

- **手工布线**（更精细控制）：
  ```
  按 X（或菜单）→ 导线工具 → 点击焊盘 → 拖动到目标焊盘
  ```

**布线的金律**：
```
短 > 快 > 美
优先级：缩短路径 > 降低阻抗 > 美观外观
```

**电流等级与导线宽度对应表**：
| 电流 | 导线宽度 | 举例 |
|------|---------|------|
| < 100mA | 8-10mil (0.2-0.25mm) | GPIO、I2C、PWM信号 |
| 100-500mA | 12-16mil (0.3-0.4mm) | MCU电源、驱动器输入 |
| 0.5-1A | 20-24mil (0.5-0.6mm) | TB6612电源、电机驱动 |
| > 1A | 32-40mil (0.8-1.0mm) | 电机功率、大容值电源 |

**布线顺序建议**：
1. **电源/地线**（优先）：+5V、+3.3V、GND 粗线
2. **关键信号**：MCU → TB6612、I2C、SPI 中等线宽
3. **普通I/O**：LED、普通GPIO 细线

**避免问题**：
```
❌ 跨越高频信号的返回地线
❌ 导线在器件下穿过（难检修）
❌ 锐角转弯（推荐圆角或45°）
❌ 长的并行走线（容易耦合干扰）

✅ 返回地线紧跟电源线
✅ 关键信号独立一条
✅ 合理分层（两面均衡）
```

#### 步骤6：验证（DFM检查）

**菜单**：工具 → 可制造性检查 (DFM Check)

**常见问题及修复**：
| 警告 | 含义 | 解决方案 |
|------|------|--------|
| 过小的焊盘间距 | 焊盘靠得太近 | 增加线宽或移动元件 |
| 导线过细 | 某处线路太细不能承载电流 | 增加导线宽度 |
| 空白区域过大 | PCB浪费材料 | 重新调整布局或接受 |
| 孤立焊盘 | 焊盘未连接 | 检查网表或手动补连 |

## 第四部分：电赛PCB的特殊考虑

### 为什么需要光耦隔离？

**场景**：
```
高功率电机电源（12V，10A+） 
    ↓
    会产生很大的电磁干扰 (EMI)
    ↓
 影响MCU的精细模拟信号
    ↓
 传感器数据出错、控制不稳定
```

**解决方案**：光耦隔离
```
MCU GPIO （3.3V，小电流）
    ↓
[光耦隔离芯片] （TLP291, PC817等）
    ↓
TB6612驱动端（与电机电源隔离）
    
好处：
✅ 电机干扰无法耦合回MCU
✅ 保护MCU免受反向脉冲损伤
✅ 可靠性大大提高
```

### 电容选择：如何不"炸"电容

**常见错误**：
```
❌ 选择了"便宜"电容，质量差劣
❌ 耐压值不足（5V电路用4V电容）
❌ 高温环境下电容失效
❌ 铝电解电容的极性接反
```

**正确的电容选择**：

#### 去耦电容（供电稳压）
| 位置 | 型号 | 规格 | 数量 | 说明 |
|------|------|------|------|------|
| IC电源脚附近 | C0603 | 0.1µF/16V | 每个IC 2-4个 | 陶瓷电容，低ESR |
| 主电源输入 | C1206 | 10µF/16V | 1-2个 | 陶瓷或铝电解 |
| 电机驱动电源 | C1206 | 100µF/25V | 2-3个 | 大容值，吸收浪涌 |

**选择原则**：
1. **耐压值 > 实际工作电压的 1.5 倍**
   - 5V电路 → 选 16V 及以上
   - 12V电路 → 选 25V 及以上

2. **优先选陶瓷电容（MLCC）**
   ```
   陶瓷（X7R/C0G） > 铝电解 > 钽电容
   
   原因：
   ✅ 陶瓷：低ESR、频率特性好、寿命长
   ❌ 铝电解：高温漂移大、易干涸
   ❌ 钽电容：贵、容易炸（浪涌电流敏感）
   ```

3. **封装选择**
   - 小容值（0.1µF）：C0603（1.6×0.8mm）或C0402
   - 大容值（10µF+）：C1206（3.2×1.6mm）或 1210/1812

4. **品牌信任**
   - 一线品牌：Samsung（三星）、TDK、Murata（村田）、Yageo（国巨）
   - 避免杂牌或翻新电容（容易失效）

#### 电机滤波电容
```
电源 ──→ [100µF/25V] ──→ TB6612 ──→ 电机
         ↓
        GND
        
作用：吸收电机启动的大电流浪涌
规格：100-470µF，25V及以上
位置：TB6612电源脚最近
```

## 常见陷阱与解决方案

| 问题 | 症状 | 原因 | 解决 |
|------|------|------|------|
| 复位无效 | MCU无法复位 | 复位电容太小或漏电 | 使用10µF陶瓷电容 |
| 噪声多 | 模拟信号抖动 | 地返回路径分散 | 汇聚所有GND到一点 |
| 电机转速不稳 | PWM有效但转速抖 | 电源不稳定 | 增加电机电源滤波电容 |
| 烧毁TB6612 | 驱动芯片冒烟 | 极性反接或短路 | 加保护二极管、检查接线 |
| I2C不通 | 传感器无响应 | 上拉电阻或SDA/SCL反接 | 检查上拉阻值和接线 |
