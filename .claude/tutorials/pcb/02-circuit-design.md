# 电赛PCB实战指南：STM32F407 + TB6612电机驱动

## 项目概述

**目标板卡**：
```
┌─────────────────────────────────────────┐
│     F407_MotorDriver PCB                 │
├─────────────────────────────────────────┤
│                                          │
│  输入：STM32F407VET6 核心板（插接）    │
│  输出：双路DC电机驱动（TB6612×2）      │
│  保护：光耦隔离、RC滤波、反向保护      │
│  指标：支持 1A/通道，5-12V电机电源   │
│                                          │
└─────────────────────────────────────────┘
```

## 第一部分：电路原理与设计

### 1. 核心电路架构

#### 权力分配
```
┌─── 12V 电源输入 ────→ [12V→5V稳压] ────→ TB6612 电源
│                                  │
│                              ┌─→ STM32F407 电源(5V)
│                              │
│                         [5V→3.3V稳压] ← MCU工作电压
│                              │
└──────────────────────────────┴─ GND (公共地)
```

**为什么分两级电源**：
- 电机驱动需要 5V（TB6612工作电压）
- MCU需要 3.3V（STM32F407规格）
- 独立稳压 → 电机干扰无法耦合到MCU

#### 完整的单路电机驱动电路
```
STM32F407 GPIO          光耦隔离器          TB6612 驱动器         电机
───────────             (TLP291-4)         (TB6612FNG)          ┌─ M+
│                       ┌─────────┐        ┌──────────┐          │
├─ GPIO_IN1 ────R1────→│IN1    OUT1├──────→│IN1   OUT1├──────────┤
│                       │          │        │          │          │
├─ GPIO_IN2 ────R2────→│IN2    OUT2├──────→│IN2   OUT2├──────────┤
│                       └─────────┘        │          │          │
├─ PWM_OUT ─────C1────→[滤波]─────────────→│ENA    OUT3├──────────┤ GND
│                                          │          │          └─ M-
└─ GND ──────────────────────────────────→│GND       │
                                           └──────────┘
                                                │
                                           ┌────┴─────┐
                                           │12V@1.2A  │
                                           │电源      │
                                           └──────────┘
```

**关键组件说明**：
- **R1/R2**：限流电阻（1kΩ），保护光耦
- **C1**：RC滤波（10kΩ + 0.1µF），平滑PWM波形
- **TLP291-4**：4通道光耦隔离器（双通道驱动用）
- **TB6612FNG**：H桥驱动芯片（集成续流二极管、过流保护）

### 2. 各部分详细设计

#### A. 电源管理模块

**框图**：
```
12V 输入电源
    ↓ [ESD防护]
    ↓ [20A保险丝]
    ├─→ [MT3608/LM2596] ──→ 5V/2A ──→ TB6612/其他模块
    │
    └─→ [LDO 5V→3.3V] ──→ 3.3V/500mA ──→ STM32F407
```

**器件选型**：

| 位置 | 器件 | 规格 | 备注 |
|------|------|------|------|
| 输入稳压 | LM2596 或 MT3608 | 12V→5V, 2A | 降压芯片，效率高 |
| MCU稳压 | AMS1117-3.3V | 5V→3.3V, 1A | LDO线性稳压，噪声小 |
| 输入滤波 | 100µF/25V | 陶瓷或铝电解 | 吸收浪涌 |
| MCU滤波 | 10µF/16V + 0.1µF×4 | 陶瓷 | 靠近3.3V电源脚 |
| 电机电源 | 100µF/25V | 陶瓷，TDK或Murata | 吸收电机启动浪涌 |

**推荐采购（嘉立创供应）**：
```
LM2596 降压芯片        ← 便宜、易买、效率75%
AMS1117-3.3V LDO       ← 标准方案
陶瓷电容 16V/25V       ← 优于铝电解
```

**PCB设计要点**：
```
电源管理区域布局
┌────────────────────────────┐
│  12V 输入 [MOLEX连接器]    │
│      │                      │
│    [保险丝]                │
│      │                      │
│  ┌─ [LM2596 + L/C] ────→ 5V输出
│  │                          │
│  └─ [AMS1117 + C] ─────→ 3.3V输出
│                             │
│  GND返回（汇聚点）         │
│                             │
└────────────────────────────┘

关键：
✅ 大容值电容靠近稳压器输入输出
✅ GND 汇聚到单一点
✅ 主电源线粗（32mil以上）
```

#### B. 光耦隔离与驱动模块

**为什么用光耦隔离**：

电机驱动产生的 EMI（电磁干扰）会通过以下路径影响MCU：
```
电机切换电流浪涌
    ↓
产生高频电磁场（MHz量级）
    ↓
感应到 STM32F407 的 ADC / I2C 信号线
    ↓
传感器读数错误、通信错误
    ↓
系统崩溃或异常行为
```

**光耦隔离的原理**：
```
光耦内部：
光源（LED）  →  光电器件（光敏二极管/三极管）
  ├─ 由MCU GPIO驱动
  └─ 完全电隔离 → 无直流通路

好处：
✅ EMI无法越过光耦
✅ 电机电源与MCU地独立
✅ 反向脉冲（反电动势）被隔离
```

**芯片选择**：

| 芯片 | 通道 | 隔离耐压 | 传输延迟 | 成本 | 推荐 |
|------|------|---------|---------|------|------|
| TLP291-4 | 4通道 | 2.5kV | 10µs | 低 | ✅ 本项目首选 |
| PC817 | 1通道 | 5kV | 10µs | 低 | 单通道备选 |
| TLP521-4 | 4通道 | 5kV | 10µs | 中 | 高可靠性选择 |
| 光纤隔离 | 多通道 | 100kV+ | 低 | 高 | 工业级（不必用） |

**推荐方案**：TLP291-4（4通道光耦）
```
引脚定义（DIP16 封装，俯视图）
┌─────────────────┐
│ GND 1       16 VCC    （驱动端电源）
│ IN1 2       15 OUT1   （驱动输出1）
│ IN2 3       14 OUT2   （驱动输出2）
│ IN3 4       13 OUT3   （驱动输出3）
│ IN4 5       12 OUT4   （驱动输出4）
│     ⋯               
└─────────────────┘

针对双电机设计：
Channel 1 (IN1/OUT1) → TB6612_IN1
Channel 2 (IN2/OUT2) → TB6612_IN2
Channel 3 (IN3/OUT3) → TB6612_ENA
Channel 4 (IN4/OUT4) → 备用或另一电机
```

**光耦隔离电路设计**：
```
MCU侧（低功率）                   驱动侧（高功率）
───────────────              ─────────────────

STM32F407
   ├─ PA5 (GPIO_IN1) ────┐
   │                      │  R_LED
   ├─ PA6 (GPIO_IN2) ────┤  (470Ω)     TLP291-4
   │                      │              ┌────────┐
   ├─ PA7 (PWM_ENA) ─────┤─────(RC滤波)→│IN   OUT├─→ TB6612
   │                      │              │        │
   ├─ GND ────────────────┘──────────────│GND     │
                                         │ VCC ←──┴─ 5V
                                         └────────┘
                                              │
                                          [10µF/16V]
                                              │
                                             GND
```

**电阻选择**：
```
MCU→光耦输入电阻：
├─ LED正向压降：1.5V（典型）
├─ 所需电流：10mA（最小驱动电流）
├─ MCU输出：3.3V（GPIO高电平）
├─ 计算：R = (3.3 - 1.5) / 10mA = 180Ω
├─ 选用：220Ω 或 470Ω（安全起见增大，降低功耗）
└─ 实际工程：470Ω（1/4W陶瓷）

光耦输出到TB6612的上拉电阻：
├─ TB6612输入高电压：VCC（5V）
├─ 光耦输出带拉下功能
├─ 选用：10kΩ 上拉到 5V
└─ 位置：光耦输出脚附近
```

**PCB 设计要点**：
```
光耦隔离模块的布置
┌──────────────────────────────────┐
│ MCU侧（左边）   │  隔离面  │  驱动侧（右边）
│                 │  ───────  │
│ ┌─STM32F407─┐   │           │  ┌─TB6612─┐
│ │ GPIO_IN1 ─┼───┼─→ [光耦] ──→│IN1      │
│ │ GPIO_IN2 ─┼───┼─→ [光耦] ──→│IN2      │
│ │ GPIO_ENA ─┼───┼─→ [光耦] ──→│ENA      │
│ └──────────┘   │           │  └────────┘
│                 │           │
│  GND─MCU        │ GND隔离   GND─驱动
│                 │           │
└──────────────────────────────────┘

关键：
✅ MCU侧GND和驱动侧GND在光耦处汇聚
✅ 隔离线不穿过光耦（保持隔离完整性）
✅ LED线（MCU→光耦）细线
✅ 输出线（光耦→TB6612）中等线宽
```

#### C. TB6612 驱动模块

**TB6612FNG 简介**：
```
双通道H桥驱动器
├─ 输入电压：4.5-13.5V
├─ 输出电流：1.2A（连续）/ 2A（峰值）
├─ 内置保护：过流保护、热保护
├─ 特性：死区管理、反向二极管、低噪声
└─ 引脚数：20脚 SSOP 或 DIP 封装
```

**引脚分配**（参考TB6612数据手册 P2）：
```
┌────────────────────┐
│ VCC (5V) ─ Pin1    │  电源输入
│ GND ──────────────┐│
│ PWMA (PWM1) ─ Pin 5
│ IN1 (DIR1) ── Pin 8
│ IN2 (DIR2) ── Pin 13
│ OUT1 ────────┐
│ OUT2 ────────┴→ 电机1
│               
│ PWMB (PWM2) ─ Pin 10
│ IN3 (DIR3) ── Pin 2
│ IN4 (DIR4) ── Pin 7
│ OUT3 ────────┐
│ OUT4 ────────┴→ 电机2
│
│ STBY (待机) Pin 9 → 3.3V 使能
└────────────────────┘
```

**电机驱动表**（控制方式）：
```
要实现电机正反转速度控制：

方向控制（IN1/IN2）：
  IN1=H, IN2=L  → 正转
  IN1=L, IN2=H  → 反转
  IN1=L, IN2=L  → 停止（通过PWM控制也能停止）
  IN1=H, IN2=H  → 刹车（快速停止）

速度控制（PWM占空比）：
  PWMA=0%   → 停止
  PWMA=50%  → 半速
  PWMA=100% → 全速

完整的控制方式：
┌─────────────────────┬──────────────────┐
│ IN1 | IN2 | PWM占空比 │   电机状态       │
├─────────────────────┼──────────────────┤
│  1  │  0  │  0-100%  │ 正转（速度可调） │
│  0  │  1  │  0-100%  │ 反转（速度可调） │
│  0  │  0  │    -     │ 停止（怠速）     │
│  1  │  1  │    -     │ 刹车（立即停止） │
└─────────────────────┴──────────────────┘
```

**保护电路设计**：
```
反电动势保护：
电机线圈
  │
  ├─→ [TB6612 内置续流二极管]
  │   + 外置 TVS 二极管（可选）
  │       （型号：SMAJ5.0A，5mm DIP）
  │
  └─ 限制反向脉冲
```

**火线线宽计算**：
```
电机功率：P = V × I = 12V × 1.2A = 14.4W

相对电流损耗允许：2% → ΔV = 0.24V

导线宽度需求：
├─ 使用铜厚 1oz (35µm)
├─ 长度约 2cm
├─ 需要宽度 W = I×L/(k×t×ΔV)
└─ 约 20-24mil (0.5-0.6mm)，选用 24mil
```

### Step 3：PCB 布线 (Routing)

**分层布线策略**：

```
顶层（信号和电源）：
├─ 主电源线：+5V、+12V（粗线）
├─ 控制信号：GPIO、PWM（中等线）
├─ MCU→光耦线：细线（可穿过高功率区下方）
└─ 接头接线柱

底层（返回地）：
├─ 连续GND返回平面（尽量完整）
├─ 电源返回路径
└─ 信号返回路径

高级技巧（如果有中间层）：
├─ 电源层：+5V完整分布
├─ 地层：GND完整分布
└─ 信号层：控制信号隔离
```

**布线优先级**：

```
第1优先级：电源线（+12V、+5V、+3.3V）
├─ 宽度：32-40mil
├─ 路径：直接到负载
└─ 位置：靠近电源输入

第2优先级：GND 返回线
├─ 宽度：32-40mil  
├─ 路径：回到GND汇聚点
└─ 覆盖面：尽量连续铺铜

第3优先级：高频信号
├─ PWM信号（TB6612_ENA）：宽度 16mil
├─ I2C/SPI（如有）：宽度 12mil
└─ 单独走线，远离高功率区

第4优先级：控制信号
├─ GPIO（IN1/IN2/IN3/IN4）：宽度 12mil
├─ 可与其他信号并走
└─ 避开电源线的变化区域

第5优先级：其他
├─ LED/指示灯：细线（8mil）
├─ 调试接口：细线
└─ 无关键要求
```

**关键布线示意**（俯视图）：

```
顶面布线图：
┌─────────────────────────────────────────────┐
│  +12V IN [FUS]  +12V ───────→ [TB6612]     │
│     ↓                            ↓          │

│     ↓                │            ↓         │

│     ↓                │            ↓         │
│   [输出C]           │         [C]         │
│     └─ GND ret      │            │         │
│                      ↓            ↓         │

│   │                        │         ↓    │

│   └────────────────────────────────────┘   │
│          ↓                                  │

│          ↓                                  │

底面布线图（GND连续返回）：

**布线间距与精确度**：

```
设置（嘉立创标准）：
├─ 最小导线宽度：8mil（0.2mm）
├─ 最小线间距：8mil（0.2mm）
├─ 最小过孔直径：10mil（0.25mm）
├─ 焊盘间距：最小 16mil（0.4mm）

自动检查：
菜单 → 工具 → 设计规则检查 (DRC)

├─ 间距检查 ✓
├─ 过孔检查 ✓
└─ 连接完整性 ✓

## 第三部分：常见问题与排障

### 问题1：电机噪声大

**症状**：电机转动时发出刺耳高频音

**原因排查**：
```
1. PWM频率过低（< 1kHz）？
   └─ 解决：增加PWM频率到10kHz，重新烧录代码
   
2. 死区时间不合理？
   └─ 解决：TB6612已集成死区，一般不需要调整
   
3. 电源滤波不足？
   └─ 解决：增加 100µF/25V 电容在TB6612 VCC脚附近
   
4. 电机本身噪声？
   └─ 解决：检查电机轴承，不是PCB问题
```

---

### 问题2：电机速度不稳定、抖动

**症状**：电机转速波动，控制不稳定

**原因排查**：
```
1. 电源电压不稳？
   └─ 排查：用万用表量TB6612 VCC，应稳定 5V ±0.2V
   └─ 解决：增加输入滤波电容（100µF + 10µF）
   
2. PWM信号干扰？
   └─ 排查：用示波器量PA7脚，应见清晰PWM波形
   └─ 解决：
      ├─ PWM与GND线尽量靠近
      ├─ 增加PWM脚的去耦电容（0.1µF）
      └─ PWM线避开高功率线
   
3. 光耦隔离性能？
   └─ 排查：检查TLP291 VCC电压是否为 5V
   └─ 解决：
      ├─ 检查隔离侧去耦电容
      ├─ 检查MCU侧的限流电阻（470Ω）
      └─ 如频繁，更换为 TLP521（更快）
   
4. 电流采样反馈？（如有）
   └─ 解决：增加RC滤波（10kΩ + 0.1µF）
```

---

### 问题3：电机不转或转向错误

**症状**：按键或指令无反应，或电机反向旋转

**原因排查**：
```
1. 接线反了？
   └─ 排查：
      ├─ 检查 M1+ / M1- 是否反接
      ├─ 检查 IN1 / IN2 的 GPIO 号
      └─ 检查光耦的输入/输出引脚
   └─ 解决：重新焊接或更改代码逻辑
   
2. 光耦隔离未生效？
   └─ 排查：
      ├─ TLP291 是否有供电（量VCC脚）
      ├─ IN脚是否接到MCU GPIO（量电压0-3.3V）
      ├─ 是否有限流电阻（470Ω）
   └─ 解决：补焊或检查焊点
   
3. TB6612使能脚 (STBY) 未使能？
   └─ 排查：STBY 脚接 VCC（5V）还是 GND？
   └─ 解决：STBY 必须接 VCC（高电平才能工作）
   
4. PWM频率太低或占空比为0？
   └─ 排查：示波器量 PWMA/PWMB 脚
   └─ 解决：重新配置STM32CubeMX的定时器PWM
```

---

### 问题4：芯片烧毁（冒烟、发热过度）

**症状**：MCU或TB6612发热烫手、有烧焦味

**原因排查**：
```
1. 电源极性反接？
   └─ 排查：检查 +12V 和 GND 接线
   └─ 解决：检查 MOLEX 连接器的引脚号
   
2. 电压过高？
   └─ 排查：输入 12V，测量 TB6612 VCC（应 5V），STM32 VCC（应 3.3V）
   └─ 解决：
      ├─ 检查 LM2596 反馈电阻（决定输出电压）
      ├─ 检查 AMS1117 输入（应 < 5.5V）
      └─ 重新焊接稳压器
   
3. 短路（最常见）？
   └─ 排查：
      ├─ 用万用表欧姆档量 +5V 到 GND（应 > 100Ω）
      ├─ 用万用表量 +3.3V 到 GND（应 > 100Ω）
      └─ 如果接近 0Ω，说明有短路
   └─ 解决：
      ├─ 用放大镜检查焊盘，看是否有锡珠
      ├─ 检查电源线 PCB 走线是否接近相邻导线
      ├─ 必要时用烙铁清洁焊盘，重新焊接
   
4. 器件选错或焊反？
   └─ 排查：对比原理图和实物
   └─ 解决：更换为正确器件或重新焊接
```
