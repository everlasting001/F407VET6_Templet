🔥 核心概念速览

为什么需要光耦隔离？

电机运行时会产生很大的电磁干扰(EMI)，直接影响MCU的模拟信号。光耦隔离能有效切断这个干扰路径，是提高可靠性的关键。

电容怎么选不会"炸"？

耐压值必须 > 工作电压的1.5倍：

  • 5V电路 → 选 16V 及以上
  • 12V电路 → 选 25V 及以上

优先选陶瓷电容(MLCC)： 低ESR、寿命长、不干涸

导线宽度怎么选？

简化规则（铜厚1oz，允许压降20mV）：

  • 100mA → 8mil (0.2mm)
  • 500mA → 12mil (0.3mm)
  • 1A → 20mil (0.5mm)
  • 2A → 32mil (0.8mm)
