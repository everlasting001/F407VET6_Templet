## 设计规则检查清单

### 电气设计 (Electrical)
- [ ] 没有浮空引脚（未连接的焊盘）
- [ ] 所有VCC和GND都已连接
- [ ] 网表完整（无冲突或重复标号）
- [ ] 电压等级正确（3.3V/5V/12V分隔）
- [ ] 电流等级和线宽匹配

### 物理设计 (Layout)
- [ ] 所有器件已放置
- [ ] 没有器件超出PCB边界
- [ ] 去耦电容距IC < 5mm
- [ ] 大容值电容靠近电源输入
- [ ] 连接器位置方便易用

### 制造工艺 (Manufacturing)
- [ ] 最小导线宽度 ≥ 8mil
- [ ] 最小焊盘间距 ≥ 8mil
- [ ] 最小过孔直径 ≥ 10mil
- [ ] 焊盘尺寸合理（易焊接）
- [ ] 没有孤立导线或铜皮

### 可靠性 (Reliability)
- [ ] 高功率线和信号线分离
- [ ] GND返回路径连续完整
- [ ] 没有锐角转弯（推荐圆角或45°）
- [ ] 高频信号有屏蔽（如需要）
- [ ] 反向二极管和保护器件已布置

## 常用PCB公式

### 导线宽度（电流承载）
```
W (mil) = I (mA) × L (cm) / (k × T × ΔV)

其中：
W = 导线宽度 (mil)
I = 流经电流 (mA)
L = 导线长度 (cm)  
k = 常数 (≈ 1.378，实验数据)
T = 铜厚 (oz，通常 1oz = 35µm)
ΔV = 允许压降 (mv，通常 10-50mv)

简化表（允许压降 20mv，铜厚1oz）：
I = 100mA → W ≥ 8mil
I = 500mA → W ≥ 12mil
I = 1A    → W ≥ 20mil
I = 2A    → W ≥ 32mil
I = 5A    → W ≥ 50mil
```

### 特征阻抗（高速信号，如需要）
```
Z₀ = √(L/C) ≈ 50Ω（标准）

对于 2层PCB，PCB厚1.6mm，铜厚1oz：
├─ 顶层到GND的距离：≈0.2mm
├─ 所需导线宽度：≈10-15mil (0.25-0.38mm)
└─ 间距：≈10mil

本项目无需严格阻抗控制（频率<10MHz）
```

### 热阻和散热
```
θ = ΔT / P

其中：
θ = 热阻 (°C/W)
ΔT = 温度差（晶体管结温 - 环境温度）
P = 功耗 (W)

例如 LM2596，功耗 P ≈ 1W：
├─ 无散热焊盘：θ ≈ 50-100°C/W → ΔT ≈ 50-100°C → 不可靠
├─ 有散热焊盘：θ ≈ 20-30°C/W → ΔT ≈ 20-30°C → 可靠
└─ 解决：一定要焊接散热焊盘（通孔连接内层GND）
```

## 元器件焊盘标准（IPC-A-610）

### 焊盘大小设计

**SMD焊盘（贴片器件）**：
```
C0603 (1.6×0.8mm) → 焊盘 1.0×1.5mm
C0805 (2.0×1.25mm) → 焊盘 1.2×1.8mm
C1206 (3.2×1.6mm) → 焊盘 1.5×2.3mm

经验规则：
焊盘面积 ≈ 器件面积 × 1.3
```

**通孔焊盘（THT器件）**：
```
直径 0.5mm 引脚 → 焊盘直径 1.5mm, 铜圈宽 0.5mm
直径 1.0mm 引脚 → 焊盘直径 2.5mm, 铜圈宽 0.75mm

过孔 (Via)：
├─ 外径：0.3-0.4mm
├─ 孔径：0.1-0.15mm
└─ 铜圈宽：0.1mm
```

**焊接质量标准**：
```
✅ 良好焊接
├─ 锡的量适当，润湿完全
├─ 焊点呈光亮、光滑、锥形
├─ 没有虚焊或冷焊
└─ 没有锡须或锡珠

❌ 不良焊接
├─ 虚焊：引脚与锡接触不完全
├─ 冷焊：锡熔合不完全，有菱形纹理
├─ 锡珠：焊盘附近有小球状锡
└─ 焊盘翘起（PCB不平或加热不均）
```

## 嘉立创EDA 工作流速览

```
创建项目
    ↓
设计原理图 (Schematic)
    ├─ 放置器件（库中搜索）
    ├─ 绘制导线连接
    ├─ 标注网络号
    └─ 检查一致性
    ↓
生成网表 (Netlist)
    └─ 导出给PCB工程
    ↓
创建PCB工程
    ├─ 导入网表
    ├─ 放置器件 (Placement)
    ├─ 布线 (Routing)
    └─ 验证 (DRC/DFM)
    ↓
输出制造文件
    ├─ Gerber 文件 (.gbr)
    ├─ 钻孔文件 (.xln)
    ├─ BOM 清单 (.csv)
    └─ 位置文件 (.pos)
    ↓
提交到工厂 (jlcpcb.com)
    ├─ 上传文件
    ├─ 等待报价 (< 2h)
    ├─ 检查预览
    └─ 下单
    ↓
收取PCB 并焊接装配
```

## 常见问题 (FAQ)

**Q: 我没有焊接经验，能做好吗？**
A: 完全可以！PCB焊接比想象简单。使用烙铁或热风枪，按照IPC标准操作，即使是初学者也能焊接出合格的产品。建议先在练习板上练习。

**Q: 嘉立创EDA和Altium哪个更好？**
A: 嘉立创适合初学者和小项目（功能够用，学习曲线平缓）；Altium功能强大但复杂昂贵，适合专业工程师。本项目推荐嘉立创。

**Q: PCB设计失误会浪费钱吗？**
A: 会。但嘉立创的DFM检查和社区反馈能大大降低风险。建议：
1. 设计后投到论坛审查
2. 等一周再下单（给自己反思的时间）
3. 找朋友或师傅review（避免低级错误）

**Q: 如果PCB有错怎么办？**
A: 可以通过加焊接线或割线来修复小错误。重大错误（如极性反接）则需要重新设计和制造。

**Q: 怎样选择可靠的器件？**
A: 
- 优先使用嘉立创库中有现货的器件（物流快、成本低）
- 选择一线品牌（Samsung, TDK, Murata, Yageo等）
- 避免很便宜的杂牌（质量难以保证）
- 数据手册中选择应用多的型号（更多人用 = 更可靠）
