⚙️ STM32F407 + TB6612 电赛PCB实战指南

从电路设计到PCB制造的完整实战教程，包含参考原理图、布局建议和故障排障

项目概述

目标板卡

F407_MotorDriver PCB ┌─────────────────────────────────────┐ │ │ │ 输入：STM32F407VET6 核心板（插接） │ │ 输出：双路DC电机驱动（TB6612×2） │ │ 保护：光耦隔离、RC滤波、反向保护 │ │ 指标：支持 1A/通道，5-12V电机电源 │ │ │ └─────────────────────────────────────┘

权力分配

12V 电源输入 ↓ [ESD防护] ↓ [20A保险丝] ├─→ [MT3608/LM2596] ──→ 5V/2A ──→ TB6612/其他模块 │ └─→ [LDO 5V→3.3V] ──→ 3.3V/500mA ──→ STM32F407
为什么分两级电源：
  • 电机驱动需要 5V（TB6612工作电压）
  • MCU需要 3.3V（STM32F407规格）
  • 独立稳压 → 电机干扰无法耦合到MCU

电源管理模块设计

框图

12V 输入电源 ↓ [ESD防护] ↓ [20A保险丝] ├─→ [LM2596] ──→ 5V/2A ──→ TB6612/其他模块 │ └─→ [AMS1117-3.3V] ──→ 3.3V/500mA ──→ STM32F407

器件选型

位置 器件 规格 备注
输入稳压 LM2596 或 MT3608 12V→5V, 2A 降压芯片，效率高
MCU稳压 AMS1117-3.3V 5V→3.3V, 1A LDO线性稳压，噪声小
输入滤波 100µF/25V 陶瓷或铝电解 吸收浪涌
MCU滤波 10µF/16V + 0.1µF×4 陶瓷 靠近3.3V电源脚
电机电源 100µF/25V 陶瓷，TDK或Murata 吸收电机启动浪涌

PCB设计要点

关键布置规则：
  • ✅ 大容值电容靠近稳压器输入输出
  • ✅ GND 汇聚到单一点
  • ✅ 主电源线粗（32mil以上）

光耦隔离与驱动模块

为什么用光耦隔离？

问题： 电机驱动产生的 EMI（电磁干扰）会影响MCU

传播路径：

  • 电机切换电流浪涌 → 产生高频电磁场
  • 感应到 STM32F407 的 ADC / I2C 信号线
  • 传感器读数错误、通信错误
  • 系统崩溃或异常行为
光耦隔离的原理：
光源（LED） → 光电器件（光敏二极管）
完全电隔离 → 无直流通路 → EMI无法越过光耦

芯片选择

芯片 通道 隔离耐压 成本 推荐
TLP291-4 4通道 2.5kV 低 ✅ 本项目首选
PC817 1通道 5kV 低 单通道备选
TLP521-4 4通道 5kV 中 高可靠性选择

光耦隔离电路设计

MCU侧（低功率） 驱动侧（高功率） STM32F407 ├─ PA5 (GPIO_IN1) ────┐ │ │ R_LED (470Ω) ├─ PA6 (GPIO_IN2) ────┤ TLP291-4 │ │ RC滤波 ┌────────┐ ├─ PA7 (PWM_ENA) ─────┤─────────────→│IN OUT├─→ TB6612 │ │ │ │ ├─ GND ────────────────┘──────────────│GND │ │ VCC ←──┴─ 5V └────────┘ │ [10µF/16V] │ GND

电阻选择

MCU→光耦输入电阻：

  • LED正向压降：1.5V（典型）
  • 所需电流：10mA（最小驱动电流）
  • MCU输出：3.3V（GPIO高电平）
  • 计算：R = (3.3 - 1.5) / 10mA = 180Ω
  • 选用：470Ω （1/4W陶瓷）- 安全起见增大

TB6612 驱动模块设计

TB6612FNG 简介

  • 输入电压： 4.5-13.5V
  • 输出电流： 1.2A（连续）/ 2A（峰值）
  • 内置保护： 过流保护、热保护
  • 特性： 死区管理、反向二极管、低噪声

电机驱动表

IN1 IN2 PWM占空比 电机状态
1 0 0-100% 正转（速度可调）
0 1 0-100% 反转（速度可调）
0 0 - 停止（怠速）
1 1 - 刹车（立即停止）

保护电路

电机线圈 │ ├─→ [TB6612 内置续流二极管] │ + 外置 TVS 二极管（可选） │ （型号：SMAJ5.0A） │ └─ 限制反向脉冲
反电动势管理： 电机断电时，电感释放的反电动势会损坏驱动电路。TB6612内置续流二极管已处理此问题。

PCB布局 (Step 2)

PCB尺寸建议

标准工程用PCB：50mm × 80mm
  • 足以容纳所有器件
  • 成本合理
  • 易于手工焊接
  • 便于安装到机器人

关键器件放置顺序

第1阶段：放置主控件 ┌────────────────────────────────────────┐ │ [STM32F407核心板位置] │ │ (预留接头空间，约 20×40mm) │ │ │ │ [TB6612 DIP20 芯片] │ │ (靠近核心板右侧，驱动区) │ │ │ │ [电源管理 LM2596 + AMS1117] │ │ (靠近左侧，电源区) │ │ │ └────────────────────────────────────────┘
布置规则（黄金法则）：
  • 主电源线 ≥ 32mil，尽量直
  • 去耦电容距离IC < 5mm
  • 高速信号避开模拟敏感区域
  • 大容值电容靠近电源输入点
  • 所有GND在底层汇聚，形成连续返回平面

PCB布线 (Step 3)

分层布线策略

顶层（信号和电源）：

  • 主电源线：+5V、+12V（粗线）
  • 控制信号：GPIO、PWM（中等线）
  • MCU→光耦线：细线

底层（返回地）：

  • 连续GND返回平面（尽量完整）
  • 电源返回路径
  • 信号返回路径

布线优先级

优先级 信号类型 线宽
1 电源线（+12V、+5V、+3.3V） 32-40mil
2 GND 返回线 32-40mil
3 高频信号（PWM） 16mil
4 控制信号（GPIO） 12mil
5 其他 8mil
布线验证：
  • ✅ 所有网络都已连接（无悬空线）
  • ✅ 线宽符合电流等级
  • ✅ GND返回路径连续
  • ✅ DRC检查无错误
  • ✅ DFM检查通过

常见问题与排障

问题1：电机噪声大

症状：电机转动时发出刺耳高频音 ▶

原因排查：

  1. PWM频率过低（< 1kHz）？
    → 解决：增加PWM频率到10kHz，重新烧录代码
  2. 死区时间不合理？
    → 解决：TB6612已集成死区，一般不需要调整
  3. 电源滤波不足？
    → 解决：增加 100µF/25V 电容在TB6612 VCC脚附近
  4. 电机本身噪声？
    → 解决：检查电机轴承，不是PCB问题

问题2：电机速度不稳定、抖动

症状：电机转速波动，控制不稳定 ▶

原因排查：

  • 电源电压不稳？
    → 排查：用万用表量TB6612 VCC，应稳定 5V ±0.2V
    → 解决：增加输入滤波电容
  • PWM信号干扰？
    → 排查：用示波器量PA7脚
    → 解决：PWM与GND线尽量靠近
  • 光耦隔离性能？
    → 排查：检查TLP291 VCC电压是否为 5V
    → 解决：检查隔离侧去耦电容

问题3：电机不转或转向错误

症状：按键或指令无反应，或电机反向旋转 ▶

原因排查：

  • 接线反了？ 检查 M1+ / M1- 是否反接
  • 光耦隔离未生效？ 检查TLP291有无供电
  • TB6612使能脚 (STBY) 未使能？ STBY 必须接 VCC（高电平）
  • PWM频率太低或占空比为0？ 重新配置STM32CubeMX的定时器PWM

问题4：芯片烧毁

症状：MCU或TB6612发热烫手、有烧焦味 ▶

原因排查：

  • 电源极性反接？ 检查 +12V 和 GND 接线
  • 电压过高？ 测量 TB6612 VCC（应 5V），STM32 VCC（应 3.3V）
  • 短路（最常见）？
    → 用万用表欧姆档量 +5V 到 GND（应 > 100Ω）
    → 用放大镜检查焊盘，看是否有锡珠
  • 器件选错或焊反？ 对比原理图和实物
预防方法： 第一次上电时用限流电源，不要直接用12V电源！
