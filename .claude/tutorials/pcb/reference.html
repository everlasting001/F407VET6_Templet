✅ PCB设计规则检查清单

电气设计

  • 没有浮空引脚（未连接的焊盘）
  • 所有VCC和GND都已连接
  • 网表完整（无冲突或重复标号）
  • 电压等级正确（3.3V/5V/12V分隔）
  • 电流等级和线宽匹配

物理设计

  • 所有器件已放置
  • 没有器件超出PCB边界
  • 去耦电容距IC < 5mm
  • 大容值电容靠近电源输入
  • 连接器位置方便易用

制造工艺

  • 最小导线宽度 ≥ 8mil (0.2mm)
  • 最小焊盘间距 ≥ 8mil (0.2mm)
  • 最小过孔直径 ≥ 10mil (0.25mm)
  • 焊盘尺寸合理（易焊接）
  • 没有孤立导线或铜皮

可靠性

  • 高功率线和信号线分离
  • GND返回路径连续完整
  • 没有锐角转弯（推荐圆角或45°）
  • 高频信号有屏蔽（如需要）
  • 反向二极管和保护器件已布置

📐 PCB设计常用公式

导线宽度计算（电流承载） ▶
W (mil) = I (mA) × L (cm) / (k × T × ΔV)
其中：k ≈ 1.378, T = 铜厚 (oz), ΔV = 允许压降 (mV)

简化表（允许压降20mV，铜厚1oz）

电流 导线宽度 应用举例
100mA ≥ 8mil (0.2mm) GPIO、I2C、PWM信号
500mA ≥ 12mil (0.3mm) MCU电源、驱动器输入
1A ≥ 20mil (0.5mm) TB6612电源、电机驱动
2A ≥ 32mil (0.8mm) 电机功率、大容值电源
5A ≥ 50mil (1.2mm) 高功率应用
特征阻抗计算（高速信号） ▶
Z₀ = √(L/C) ≈ 50Ω（标准阻抗）
本项目提示： 你的项目频率 < 10MHz，无需严格阻抗控制。只需确保导线间距和宽度合理即可。
热阻和散热计算 ▶
θ = ΔT / P
其中：θ = 热阻, ΔT = 温度差 (°C), P = 功耗 (W)

例如 LM2596，功耗 P ≈ 1W：

无散热焊盘 θ ≈ 50-100°C/W → ΔT ≈ 50-100°C → 不可靠
有散热焊盘 θ ≈ 20-30°C/W → ΔT ≈ 20-30°C → 可靠
关键结论： 一定要为大功耗芯片（LM2596等）焊接散热焊盘，并连接到内层GND！

✨ 焊接质量标准 (IPC)

✅ 良好焊接

  • 锡的量适当
  • 润湿完全
  • 焊点呈光亮、光滑
  • 呈锥形（不是球形）
  • 没有虚焊或冷焊

❌ 不良焊接

  • 虚焊：接触不完全
  • 冷焊：有菱形纹理
  • 锡珠：焊盘附近有小球
  • 焊盘翘起
  • 焊点黑暗无光

❓ 常见问题 FAQ

导线宽度不对会怎样？ ▶

后果： 线路发热、压降过大、甚至断线烧毁

解决： 用上面的公式或对应表选择合适的线宽。100mA用8mil，1A用20mil，遵循这个经验值一般没问题。

过孔间距太小会怎样？ ▶

后果： 制造难度大、容易钻坏相邻焊盘、工厂可能拒单

解决： 保持最小间距 ≥ 8mil (0.2mm)。嘉立创的DFM检查会提醒你。

去耦电容放太远会怎样？ ▶

后果： 无法有效吸收浪涌电流、IC电源不稳定、系统重启或崩溃

解决： 去耦电容距离IC < 5mm，直接靠近电源脚。

GND返回路径太长会怎样？ ▶

后果： EMI干扰大、信号噪声高、模拟电路工作异常

解决： 每个电流都要有最短的GND返回路径。底层尽量铺满连续GND。

芯片烧毁怎么办？ ▶

排查步骤：

  1. 检查电源极性是否反接
  2. 用万用表量电源电压和地之间是否短路
  3. 检查器件型号是否选对（有没有用错5V的器件在3.3V上）
  4. 检查焊接有没有问题（虚焊导致短路）

预防： 设计时用 DRC 检查，焊接前再检查一遍，第一次上电时用限流电源。
