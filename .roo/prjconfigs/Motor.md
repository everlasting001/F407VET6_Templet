# 电机项目配置

## TB6612 电机驱动配置

### PWM 配置
- 定时器: TIMx (根据实际 CubeMX 配置)
- 频率: 10-50 kHz
- 占空比: 0-100%

### 方向控制
- AIN1/AIN2: 正反转控制

## 28BYJ-48 步进电机配置

### 控制时序
- 使用 4 步或 8 步时序
- 延时: 根据实际转速要求调整

### 速度控制
- 步进延时: 2-20ms (典型值)
- 加速/减速曲线: 建议使用梯形加速

> 详细参考 `.claude/prjconfigs/Motor.md` 或 `.roo/docs/datasheets/` 中的数据手册。
