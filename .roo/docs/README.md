# .roo/docs — Roo Code 文档目录

本目录为 Roo Code 提供硬件相关的技术文档、数据手册、原理图等参考文件索引。

## 子目录

- **datasheets/** — 硬件数据手册和规格书（请参阅 `.claude/docs/datasheets/`）
- **htmls/** — HTML 格式的技术文档
- **pcb/** — PCB 设计文件（封装库、原理图库）
- **schematics/** — 原理图 PDF 文件

> **注意**: 所有大型二进制文档（PDF、图片等）集中存储在 `.claude/docs/` 目录下。
> 本目录为 Roo Code 提供相同的索引和访问路径。如需访问具体文件，请引用 `.claude/docs/` 中的对应路径。
