# 电机控制参数

> 此文件是 `.claude/memory/motor-params.md` 的副本，供 Roo Code 使用。

## TB6612FNG 直流电机驱动

| 参数 | 值 |
|------|-----|
| 最大电流 | 1.2A / 通道 |
| 电机供电 | 4.5-13.5V |
| 逻辑电压 | 3.3V / 5V |
| 通道数 | 2 |
| 控制方式 | PWM + 方向 |

## ULN2003 步进电机驱动

| 参数 | 值 |
|------|-----|
| 类型 | 达林顿管阵列 |
| 通道数 | 7 (使用 4 通道) |
| 最大电流 | 500mA / 通道 |
| 兼容 | 28BYJ-48 步进电机 |

## 28BYJ-48 步进电机

| 参数 | 值 |
|------|-----|
| 类型 | 4 相单极性 |
| 电压 | 5V |
| 减速比 | 1:64 |
| 步进角 | 5.625° |
| 步数/圈 | 2048 |

## 灰度传感器

| 参数 | 值 |
|------|-----|
| 供电 | 5V |
| 检测距离 | 1-3 cm |
| 输出 | 模拟/数字 |
| 通道数 | 8 |
