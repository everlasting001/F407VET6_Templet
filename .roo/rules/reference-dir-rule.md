# docs/reference 目录排除规则

## 规则

`docs/reference/` 目录**不是**项目源代码的一部分。它仅作为外部参考资料，**不得**被包含在构建中或被视为项目代码。

## 适用范围

- 所有构建配置（CMakeLists.txt、Makefile 等）
- 代码索引工具（clangd、IntelliSense 等）
- 代码搜索和导航
- AI 代码生成上下文

## 具体约束

1. **构建排除** — `docs/reference/` 下的任何 `.c`/`.h` 文件不得被添加到 `target_sources()` 或 `target_include_directories()` 中
2. **参考用途** — 该目录下的代码仅作为设计参考和灵感来源，生成的代码必须为原创实现
3. **不修改** — 不对 `docs/reference/` 下的任何文件进行修改
4. **不索引** — 该目录应被 `.clangd` 或类似工具的索引排除

## 原因

该目录包含来自外部项目的参考代码（BSP 驱动、应用示例等），用于理解硬件接口和驱动模式。这些文件使用不同的编码风格和架构约定，不应直接编译或链接到本项目。
