# 代码审查清单

> 原始文档: `.claude/rules/code-review-checklist.md`

## 通用检查项
- [ ] 所有 HAL 调用检查返回值
- [ ] 中断服务函数无阻塞调用
- [ ] 全局/静态变量使用 `volatile` 修饰（ISR 共享）
- [ ] 无动态内存分配（malloc/free）
- [ ] DMA 缓冲区为全局或静态

## STM32 特定检查
- [ ] USER CODE 标记内修改
- [ ] 初始化顺序正确
- [ ] 时钟配置正确
- [ ] 外设引脚无冲突

## 代码风格
- [ ] 命名规范一致
- [ ] 函数长度合理
- [ ] 注释完整清晰
