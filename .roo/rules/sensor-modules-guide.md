# 传感器模块指南

> 原始文档: `.claude/rules/sensor-modules-guide.md`

## MPU6050 6 轴 IMU

### 寄存器快速参考

| 寄存器 | 地址 | 用途 |
|--------|------|------|
| ACCEL_XOUT_H | 0x3B | 加速度计 X 轴高字节 |
| ACCEL_YOUT_H | 0x3D | 加速度计 Y 轴高字节 |
| ACCEL_ZOUT_H | 0x3F | 加速度计 Z 轴高字节 |
| GYRO_XOUT_H | 0x43 | 陀螺仪 X 轴高字节 |
| GYRO_YOUT_H | 0x45 | 陀螺仪 Y 轴高字节 |
| GYRO_ZOUT_H | 0x47 | 陀螺仪 Z 轴高字节 |
| TEMP_OUT_H | 0x41 | 温度传感器高字节 |

### 数据读取流程
1. 写入 `ACCEL_XOUT_H` 地址到 I2C 从机
2. 连续读取 14 字节 (加速度计 6 + 温度 2 + 陀螺仪 6)
3. 合并高低字节为 16 位有符号整数

### 校准方法
- 加速度计: 静止时 Z 轴应输出 1g
- 陀螺仪: 静止时各轴应接近 0
- 偏差校准: 采样 100 次取平均作为偏移量

## 8 路灰度传感器

### 配置流程
1. 供电 5V
2. 传感器输出接 STM32 ADC 输入
3. 配置 ADC 为连续扫描模式
4. 读取 8 通道 ADC 值

### 阈值校准
- 白底: 8 通道 ADC 值 < 512 (假设 12-bit ADC)
- 黑线: 8 通道 ADC 值 > 2048
- 或动态阈值: `(max + min) / 2`
